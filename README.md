# LARPing as an Extrovert: A practical guide to networking, small talk, and other social side quests

This repo contains the slides for a talk I hope to give at [BarCamp Philly](https://barcampphilly.org/) and the resources I used to create it. I encourage you to present this talk with any adjustments as long as credit is given to myself and those I've cited. If you see anything that needs correcting, kindly raise an Issue or open a Pull Request and you too shall be cited as a contributor to this talk!

## Slides

To start the slide show:

- `pnpm install`
- `pnpm dev`
- visit <http://localhost:3030>

Edit the [slides.md](./slides.md) to see the changes.

Learn more about Slidev at the [documentation](https://sli.dev/).
