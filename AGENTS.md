# AGENTS.md

Slidev talk deck (not an app). No tests, lint, or typecheck.

- Content lives in `slides.md` (headmatter: theme `slidev-theme-tahta`, variant `signal`). `pages/imported-slides.md` is pulled in via `src:` from `slides.md`; `components/` holds Vue components, `snippets/` code imported by slides.
- Use pnpm (`pnpm install`, `pnpm dev` -> http://localhost:3030, `pnpm build`, `pnpm export`). Don't add `package-lock.json`. Deploys via Netlify (`netlify.toml`: `pnpm run build`, publishes `dist/`, Node 24), so don't commit `dist`.
- `pnpm export` uses the `playwright-chromium` devDependency (build script allowlisted in `pnpm-workspace.yaml`; don't remove `allowBuilds`). Node >=22.12 required (`engines`).
- Slide separators are `---`; per-slide frontmatter goes in a `---` block directly after. No blank line after the opening `---`, or it is parsed as body text, not frontmatter; a closing `---` is required. The last HTML comment in a slide is its speaker notes.
- Much of `slides.md` is still the default Slidev template ("What is Slidev?" etc.) and may be placeholder content to replace rather than preserve.
- Slidev's drag feature can append empty `dragPos:` frontmatter slides to `slides.md`; delete them.
- `.agents/` is generated by the Slidev skills install (`skills: true` in `pnpm-workspace.yaml`).
- Talk is credit-required (see README); keep citations when editing content.
